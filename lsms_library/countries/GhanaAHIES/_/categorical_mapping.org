#+title: GhanaAHIES categorical mappings

Country-level label harmonisation for the Ghana AHIES (GSS, 2022-2024).
Tables named after a served column (=Roof=, =Floor=) are applied
automatically at API time; =harmonize_education= is applied by the wave
scripts through =ghanaahies.harmonize_education_labels=.

* harmonize_education

Maps the composite "<level> <grade completed>" label the wave script builds
from =s2aq3= (highest level attended) and =s2aq4= (highest grade COMPLETED at
that level; 0 = none) onto the canonical ordinal vocabulary in
=lsms_library/categorical_mapping/canonical_education_labels.org=.  The
grade ladders are the field manual's Appendix 5: Primary 1-6 (6 completes the
cycle), Middle Form 1-4 (4 completes), JSS/JHS 1-3 (3 completes), Secondary
(O/A level) Form 1-5 (5 = O-level complete) and Lower/Upper 6 = 6-7 (A-level
complete), SSS/SHS 1-3 (3 completes; 4 completes for the 2007-10 four-year
SHS cohort).  A bare graded level (grade missing) is mapped conservatively to
the "some" rung.  =s2aq1= 'Never attended' rows are labelled 'Never attended'
here (-> 'No education').  Tertiary levels map from the level alone, as the
GhanaLSS sibling does (the survey asks the level attended, not completed).

* Roof / Floor

Identical to the GhanaLSS tables so the two Ghana series agree.  The housing
wave script first normalises the AHIES =s7eq3= / =s7eq2= labels to the GLSS7
intermediate spellings (=Metal Sheet=, =Cement/Concrete=, ...); these tables
take them to the canonical cross-country vocabulary at API time.
