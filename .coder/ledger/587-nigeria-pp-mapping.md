## §3 Definitions in force

- `community_prices.Price` = "surveyed prevailing price of one unit `u` of item `j`" (`lsms_library/data_info.yml:1434-1451`; Nigeria `data_scheme.yml:747-753`).  A division is a derivation and carries a registry key.
- `j` → shared `harmonize_food` Preferred Label; `u` → shared base Preferred unit (`data_scheme.yml:756-767`).
- `u = 'Unknown'` is the missing-unit sentinel; never a unit (`data_info.yml:62-93`).
- An unplaced recorded C8 label stays as recorded, verbatim, no factor (GH #1095 ruling, CONTENTS.org L2057-2062).
- W1 labels stay weightless; a stated weight is not a factor (GH #1035, CONTENTS.org L493-555).
- W4-PH food "40. DERICA/TIN" / "120. SACHET" serve derica / packet/sachet (GH #1033 ruling, CONTENTS.org L341-347).
- Add no attribute the source did not record: "Pepper", "Groundnuts", "Maize (shelled)" stay native (GH #1144, CONTENTS.org L20-25; #1537 L4059-4071).
- Normalisation used for "same label" (`build_mapping.py: item_norm, unit_tokens`): strip a `NNN.` prefix and the W1 category prefix, casefold, drop `etc`, keep alphanumerics; units also drop parenthesised stated weights and alias kilograms→kg, grams→g, litres→l, centilitres→cl, millilitre→ml, pieces→piece.  Anything else is a judgement row, never silently equal.

## §4 Invariants and assumptions

- PP and PH are distinct rounds with distinct `t` (`pp-ph` skill); PP `t` = `PP_QUARTER` (`nigeria.py:600`).
- Public grain `(t, v, j, u, variety, obs)`; W3 first/second are `obs` 1/2; W1/W2 `variety` = full native item code; W3–W5 `unknown_variety` (CONTENTS.org L3925-3950).  No proposed `j` collides within a source (checked; the rejected W3 161→"Palm oil" alternative would collide with code 50).
- Never join a PP code to the `u` table by number: `u` Code 22 = "Basket Medium", 32 = "Basin Medium" (W1 meanings), 1 = Kg while W1 PP code 1 is a tomato cup.
- `_canon_community_unit` is a substring matcher written for other cards.  Verified wrong on PP labels: `millilitre`→`l` (W1, 460 rows), `4. CENTLITRES (CL)`→`l` (W5, 36), `251. BAG OF 20 SACHETS`→`Sack/Bag` (W4 103, W5 464), `congo/mudu`→`Congo` (W1, 1,841), `MEDIUM DERCA`→NA (W2, 68), `tomatoes cup`→NA (W1, 233).
- No raw microdata in commits: only codebook labels and per-code counts from the sealed audit.
