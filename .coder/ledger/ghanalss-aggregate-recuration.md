## §3 Definitions & conventions in force

- The **served `j`** is the country `Preferred Label`, a bijection onto
  the 215 distinct labels of `_/categorical_mapping.org` `harmonize_food`
  (`slurm_logs/ghanalss_aggregate_labels/LANDED.org`, "Verification";
  re-measured here: 215 = 215, 0 off-axis, 0 undelivered).
- **The gate** (`add-feature/food-acquired/SKILL.md` §"Bucket-design rules"):
  for every multi-member bucket `max(beta) - min(beta) < 1.348 * sigma_min`,
  sigma_min the smallest SE among the bucket's well-estimated constituents.
- **Beta is per-fit**: CFE's beta is a rank-1 factor identified up to scale
  (`cfe/regression.py:estimate_beta`), so a group is gated on ONE fit that
  contains all its members (full fine fit, else a probe of the members
  together beside the same dense reference foods).
- **Cross-wave coarse labels** (`Rice`, `Gari`, `Fish (smoked)`,
  `Millet/Sorghum`, `Oil (palm)/Shea Butter`, `Macaroni/Spaghetti`) join a
  group only if the within-wave constituents pass -- the #937 precedent
  (`validation.org` "Published partition": "Earlier waves contain at most
  one member of each selected group, so the map only renames").
- `labels='Aggregate'` contract: `.claude/skills/add-feature/food-acquired/aggregate-labels/SKILL.md`
  (Contract B, `LabelUnavailableError` / Feature degrade, PR #550).
- Scoring in the validation runs uses `min_goods=1` explicitly
  (`ghana_validation.evaluation_arguments`), per #937's `e70b8df` -- never
  `score_w`'s default. Whether the partition RANKING is stable in
  `min_goods` (1 vs the fit cutoff 9) is GH #939 and is NOT resolved here.

## §4 Invariants & assumptions

- `STANDING.md §4` IO/cache constraints: no `dvc` CLI, reads via the API.
- **`_/categorical_mapping.org` is in every GhanaLSS table's input hash**
  (`CONTENTS.org` "One vocabulary for seven waves"), and so is every `_/*.py`
  (`Wave._input_hash` `binp:` loop). Checking out #937's `nutrition.py`
  alone graded all four warm parquets STALE (measured); it was restored and
  is re-applied in the SAME commit as the org edit so the country re-warms
  ONCE.
- **A partial `Aggregate Label` column is a silent merge, not a partial
  feature** (GH #925, `TABLE_AUDIT.org` Issue 9): every one of the 215 rows
  carries a value; a singleton carries its own Preferred Label.
- `publish()` must append ZERO rows: post-#935 no delivered label is absent
  from the country table (`inventory.yml`: `delivered_labels_absent_from_country: []`).
- The default `j` does not read the Aggregate column, so the four
  `tests/test_currency_denominated_units.py` GhanaLSS pins moved at
  `8766f882c` for #935 (kgvalue 568,624; unitvalue 1,676,093; unitprice
  189,656; units 1,694,623) must NOT move here.
- `tests/test_ghanalss_aggregate.py` came from #937 asserting wave PLs ⊆
  country PLs and members ⊆ wave PLs; both are FALSE post-#935
  (`Potato/Sweet Potato`, `Sorghum`, `Guinea Corn` are wave-only). Re-keyed
  to the country axis; the wave<->country bijection is already pinned in
  `test_ghanalss_food_label_canonical.py` and is not duplicated.
- `test_ghanalss_nutrition.py::test_energy_2016_17_measured` pins a
  pre-#935 measurement; #935's PR body says `nutrition` "will change". If
  it moves after the re-warm the cause is #935's FCT changes, not this
  column -- report, do not re-pin.

## §6 Open questions for the human

- `Margarine` vs `Margarine/Butter`: never co-occur in a wave, no `Butter`
  label anywhere to test against -> singletons by default. A human may
  prefer the coarse `Margarine/Butter` for cross-wave continuity.
- `Potato` vs `Sweet Potato`: Sweet Potato is own-production only from
  1991-92 on, so no purchased-basis co-occurrence -> singletons, honouring
  the #935 ruling that folded the GLSS1/2 compound INTO Sweet Potato.
- Generic `Sugar` (1987-88..2012-13) stays outside `Sugar (cubed/granulated)`
  on #937's semantic caution (early source = "Sugar, candy, honey and
  sugarcane"); the cross-wave series is therefore NOT continuous for sugar.
- GH #939: stability of the ranking in `min_goods`. Not attempted.
