## §6 Open questions for the human
1. **RULED (@ligon 2026-10-23): accepted.** **`Piece` for the ten count goods whose text names no unit** (Trousers, Battery, Watch, Hand hoe, Panga, Sickle, Axe, Bicycle, Foam mattress, Mosquito net; 16,960 rows).  An inference from the struck count cell, not a transcription.  `Malawi/_/CONTENTS.org` said before #827: "A blank unit is *unknown*, not 'one piece'"; that was written on the premise that "the unit is a free field, not pre-printed", which the form contradicts for these items.  Reversible: one dict.
2. **RULED (@ligon 2026-10-23): yes, as a registered derivation, on priced rows.** Was: "Serve `NumberOfUnits = 1` on the 17 struck items?  The form fixes the count with the item ("1 day", "(bottle)") but records none; left NA."  Now `NumberOfUnits = 1` on the 20,042 struck rows with a recorded price and no count, key `Malawi::community_prices::struck-item-one-unit` (`Malawi/_/derivations.yml`).  Unpriced struck rows (6,990) keep NA: Niger's `one-item-per-price` stamps only rows carrying a price (its reshape serves no unpriced row), and a count qualifies a price.  The six 2019-20 CK50 rows at 0 MK are inside the 20,042 and stamped (a recorded price).  **Round 2 (@ligon 2026-10-23): cigarettes (CK33) EXCLUDED** -- bimodal packet / single-stick prices (~541 of 1,599 priced rows at single-cigarette prices), so a 1 would assert "one packet" on about a third of them; the 1,599 priced cigarette rows keep NA and no key, `u` stays `Packet` (`malawi._CK_ONE_UNIT_EXCLUDED`).  The first commit (`3be88e0ad`) stamped 21,641, cigarettes included.
3. **RULED (@ligon 2026-10-23): `Unknown` accepted.** **2013-14 codes 22 / 23 under the IHPS household list** (22 SATCHET/TUBE, 23 OTHER (SPECIFY)).  Evidence for: 2013-14 never uses code 20 (2010-11 479, 2019-20 937); 22 falls on items 2010-11 puts on code 20 (Paraffin, Charcoal, Clothes Soap, Toothpaste, Aspirin, Fansidar); 23 on items 2010-11 puts on 21 (Chitenje, Aspirin, Charcoal, Firewood); the IHPS 2013 household Module G and Market questionnaires print 22 / 23 so.  Against: neither the IHPS 2013 price page (Market p. 12) nor IHS5 Community p. 20 prints a unit legend (only IHS3 Community p. 20 does), and `COM_MOD_K_13` has no value labels, so nothing printed says which list 2013-14 was entered on; adopting the whole list would also send 2013-14's 12 (5 rows), 16 (3) and 21 (1) to `Unknown` as unprinted (`_IHPS13_UNPRINTED_CODES`).  Code 23 is `Unknown` under either reading; the contested set is 47 rows of code 22.
4. **`map_index`'s null-`u` -> `'unit'` rename** (framework) is undocumented and serves a spelling `_U_SENTINELS` does not know.  Malawi no longer reaches it for community_prices; other tables / countries may.
5. **CK42 label drift**: 2010-11's Stata value label says "(per 50kg)"; the printed IHS3, IHPS and IHS5 pages and the IHS5 label say "(per 50kg per kilometer)".  The printed form governs (`50 kg per Kilometre`).  It is a RATE: `transformations._parse_explicit_metric('50 kg per Kilometre')` returns 50.0, so it must never be fed to a kg conversion (no library code feeds `community_prices.u` to one today).
6. **CK33 Cigarettes (`Packet`) prices are bimodal**: ~541 of 1,599 priced rows sit at single-cigarette prices (2010-11 206/747 <= 20 MK; 2013-14 43/192 <= 50 MK; 2019-20 292/660 at 20-50 MK).  Not relabelled or rescaled; recorded in CONTENTS.org.
