Aggregates only (counts, totals, shares); no household, holder or plot
identifiers.  Measured 2026-10-23 on a sucoder /local clone.  Base =627d3cfdf=
(#1257's head, GH #820) in a detached worktree; development =9a0ed5f3c=; the
branch =fix/1252-1253-1256-ethiopia-bundle-20261023=, built once per commit.
Every build: its OWN fresh =LSMS_DATA_DIR= (cold; =dvc-cache= symlinked to the
shared L1), =PYTHONPATH= = the checkout under test (import identity asserted),
=OPENBLAS/OMP/MKL_NUM_THREADS=1=, =LSMS_BUILD_WORKERS=1=, =nice -n 19=.

*Running a test file against a base checkout*: =tests/= is a package
(=tests/__init__.py=), so pytest prepends the TEST FILE's repo root to
=sys.path=.  Running the branch's test file by path from inside a base checkout
silently imports the BRANCH's =lsms_library= (it did, once, here: 14 passed
"on base").  =scripts/run_test_on.sh= copies the file into the checkout under
test, runs it there, and deletes the copy.
