#+title: GH #1259 -- Site Q's reference from strictly positive values: raw records
#+date: 2026-10-23

Measurements behind the #1259 change to =lsms_library/quantity_audit.py= (the
reference quantile and the 30-row cell floor now count strictly positive values
only). Everything here is aggregated. Per-row offender lists carry household
ids, so they stayed in scratch and are not committed.

* Data under test

| root | what | vintage |
|------+------+---------|
| cold | all 16 =crop_production= countries, cold-built at development =9a0ed5f3c= (=build_cold.py=) into a private =LSMS_DATA_DIR= | 2026-10-23 |
| cache20261019 | the shared warm cache (=~/.local/share/lsms_library=), read-only: =crop_production=, =food_acquired=, =plot_features= | built 2026-10-19; grades =stale= against =9a0ed5f3c= for *every* screened parquet |
| pr1263-tanzania | Tanzania =crop_production= built from PR #1263's head =5239daecd= into a private root | 2026-10-23 |

The rule comparison is always *the same frames under both rules*, so the
staleness of cache20261019 does not confound the deltas. It only means those
absolute counts describe the 2026-10-19 builds.

* Scripts

All of them are read-only against their data root and assert which
=lsms_library= they imported.

| file | what |
|------+------|
| =dump_rows.py= | Per-row reference, rung and verdict under whichever rule the imported checkout ships. It calls the module's own =_cell_reference=, cross-checks the count against =audit_quantities=, and writes per-row output to scratch and a count summary (=firing-*.json=). |
| =diff_rows.py= | Joins a development dump and a branch dump. Classifies every row that leaves or arrives, and counts every rung transition (=diff-*.json=, counts only). |

| =ab_timing.py= | Base vs branch =audit_quantities= timed interleaved in one process. |

| =build_cold.py= | The cold build. |
| =hash_census.py= | A copy of the 1218 census: every L2-country hash, build fingerprint and L2-wave input hash. |

=slurm_logs/gh857_quantity_screen/sensitivity_sweep.py= was re-run unchanged
from each checkout (=sensitivity-*.txt=). Only its count lines and its ratio
