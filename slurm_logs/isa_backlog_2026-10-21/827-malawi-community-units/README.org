On the 21 food items (19 unit-asked + Soft Drink / Beer, which are
struck): 6,357 unit-less rows = 3,324 not available (no price) + 3,003
priced Soft Drink / Beer (now =Bottle=) + 26 priced unit-asked rows with a
blank (13) or off-list (13) code (now =Unknown=) + 4 other
(=results/food21.json=).  Against household purchase unit values on
=(t, v, j, u)= the recovered rows match 0 cells (=results/hh_compare.json=).
The issue's "recovering the blank half would double the usable yardstick"
does not hold.

fixed unit (Piece 16,960, 50 kg Bag 3,394, Bottle 3,393, Packet 1,697,
50 kg per Kilometre 1,697, Day 1,490), 9,875 =Unknown=.  Price,
