  country script that walks writes walked ids.  The flag rides into the

  build walked it is never walked again on any warm route.  The brief's "the
  flag is lost through a parquet round trip" is false here (pandas 3.0.6,
  pyarrow 25.0.1).
- *L2-wave parquets are PRE-walk* (=Wave.grab_data= / wave scripts emit raw
  ids; no wave script calls =id_walk=).
- *Applied twice today: yes, on every cold, warm and Feature read of the
  tables below* (never under =assume_cache_fresh=, which walks nothing).  22
  =_finalize_result= walks per route (cold, warm_same, warm_fresh, Feature);

  re-applications (classified =walked=: no =K - V= id, thousands of =V - K=
