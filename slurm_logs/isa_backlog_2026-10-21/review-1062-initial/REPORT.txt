panel_ids.json/updated_ids.json. Thus the pin inside the recipe never runs.

arithmetic correctly computes the wrong requested coverage. The subprocess
trace shows no wrapper Python subprocess was launched for either sibling.

This is a demonstrated regression under an ordinary valid cache state,
without a fabricated stale hash, input mutation, or acquisition. The official
order sweep misses it because its Make tests remove the requested sibling
first, and its subset tests use full warm caches with the default backend.
