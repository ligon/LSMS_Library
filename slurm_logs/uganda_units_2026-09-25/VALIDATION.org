#+author: Sue
#+date: 2026-09-26

* Result and scope

Missing unit reports previously shared the label =---=, which received an inferred kilogram factor.
The correction distinguishes expenditures without quantities (=Value=, with quantity equal to expenditure) from reported quantities without units (=Unknown=).
Neither receives a kilogram factor.
The country catalog also recovers recorded measurement labels without turning undecoded codes into invented physical names.

The final library source is =72f8bce34=.
All seven outputs and three additional price modes were cold-rebuilt/replayed and match the first candidate =a45d319bd= exactly, including values, dtypes and canonical keys.
The final change fixes a categorical-unit assignment regression found by independent review; it does not change ordinary raw-data output.
The comparison base is merged GitHub development =4c2223aa119381ebcd8aea05fc2f9d26c3026028=, including fraction-parser PR #963.
The baseline checkout at =b22720d25= differs only by its ledger; a source/test diff guard verified equivalence.
No nutrition code, factor policy, published output or nutrition test baseline was changed.

* Cold comparison

Both revisions built these seven outputs from empty private L2 caches with the same shared content-addressed L1 blobs.
The environment was Python from the node's mounted venv, pandas 3.0.6, numpy 2.4.6 and pyarrow 25.0.1.
Package and country-config imports were asserted to use the intended checkout.

See [[file:validation/FINAL_REVIEW.md][the independent review]] and [[file:validation/final_probe_summary.json][scalar-oracle results]].
