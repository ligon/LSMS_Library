* What is actually wrong (corrected)
=conversion_to_kgs= infers a kg-per-unit factor for *every non-metric label that
carries an Expenditure*.  =Value= gets one for exactly the same reason =Heap=
(0.2268), =Bowl= (0.6048) and =Piece= (0.2041) do.

*My earlier causal claim was FALSE.*  I wrote that the factor is degenerate
"because =Quantity == Expenditure=".  It is not: in =conversion_to_kgs=,
=po= is the median *Expenditure*, and =Quantity= enters only through
=Kgs = Quantity x unit_conversion=, which is NaN for =Value=.  *The inferred
factor does not depend on =Quantity= at all* -- verified by holding Expenditure
fixed and scaling =Value=-row =Quantity= by 1x / 3x / 100x and by a constant
sentinel: the factor is =1.9= in every case.  GhanaLSS's =all= (142,997 rows)
and =none= (2,304 rows) escape only because their =Expenditure= is 100% null --
an accident, not a recognition.

What *does* depend on =Quantity == Expenditure= is the SYMPTOM: with it,
=food_prices(kgvalue) = Expenditure / (Expenditure x f) = 1/f= exactly.  That
link is real (GhanaLSS: =1/0.49139133 = 2.035038=, per-wave =std= 2.1e-17 in six
of seven waves).

* The diagnosis (EL's -- unchanged, and it survives)
=Value= is not a non-physical unit.  Value = Quantity x Price, so Value is
denominated in LCU, and Value / Price = Quantity: *prices are the units in which
value measures quantity*.  The kg factor for =Value= exists and equals
=1/price=.  The bug is a *granularity error* -- =conversion_to_kgs= returns one
factor PER UNIT LABEL, but =1/price= varies over =(j, t, m)=.  NaN is therefore
the honest INTERIM state, not a terminal verdict.

* The detector: DROP IT, or re-found it
The proposed =Quantity == Expenditure= detector tests the symptom, not the
cause.  *Panama 1997 evades it*: 11,072 of Panama's 17,821 =Value= rows are in
1997, where =Quantity == Expenditure= is *0.48%* (99.1% carry the =7.70=
sentinel of #777).  Country-level Panama is 37.9%, nowhere near "~all".  Recall
is 1 of the 2 countries we actually hold.
*Decision: ship Step 1 without a detector.*  A hardcoded set covers everything
in the corpus today (662 distinct unit labels; only =value=, in GhanaLSS and
Panama).  A detector founded on the real cause -- "a non-metric label whose
inferred factor comes from a cell with no kg anchor" -- is a separate piece of
work and should not ride along.
