The PR records that importing this dependency hangs on Windows without the bundled libmagic DLL.
=.github/workflows/ci.yml:81-89= manually uninstalls =python-magic= and installs =python-magic-bin= before the successful smoke test.
=docs/getting-started.md:10-12= nevertheless promises native Windows reading after the ordinary pip installation.

Release the upstream platform-specific dependency fix, raise the LSMS dependency floor, remove the temporary swap and rerun Windows CI on the declared installation.
The existing Windows CI result is 333 passed and one skipped after the swap; no Windows host was available for this local review.
This is a merge condition for the current support claim, not evidence of a Linux regression.

** P1: Wave.resources is still unsafe under the Windows default encoding

=lsms_library/country.py:836-843= opens wave =data_info.yml= without an explicit encoding.
=Wave.grab_data= calls that reader at lines 1360-1363, before its fixed UTF-8 parser can help.
The exemption =("country.py", "resources")= in =tests/test_windows_portability.py:57= matches both =Country.resources= and =Wave.resources=, but the corresponding ASCII guard at line 160 checks only country-level =*/_/data_info.yml=.

With default decoding simulated as cp1252, =Country('Tajikistan')['2003'].resources=, =data_scheme=, =features= and =grab_data('sample')= fail with =UnicodeDecodeError= at byte 0x90, offset 1808.
The UTF-8 control reads all six table declarations.
The coordinator independently reproduced the =resources= failure; the reviewer also found 17 wave configs whose parsed values differ under cp1252.
These are current shipped files, not a hypothetical future character.

Set UTF-8 on =Wave.resources=, distinguish the classes in the exemption mechanism, and exercise actual wave APIs in the Windows tests.
Accept the resulting rebuild: a source-only simulation of this one encoding correction changes all eight sampled build fingerprints.
Preserving an incorrect ASCII exemption to avoid rebuilding would leave the advertised reader path broken.
