* Change and prior art

The metric parser reads the entire numeric token, using decimal commas with one or two fractional digits, leading-zero decimal commas at any precision, and three-digit thousands groups unless the token starts with the literal =0,=.
Thus =1,5 L= is 1.5 kg-equivalent under the existing volume-as-mass option, =0,125 kg= is 0.125 kg, and =1,500 kg= is 1500 kg.
Malformed separators and numeric suffixes decline; fractions, SI scales, unit word boundaries, existing range endpoints, numbered survey labels and existing inner sizes in multiplier labels are preserved.

Work reuses the previously unpublished implementation =0020cfdac= and tests =15d2d567f=, recovered without rewriting their attribution.
The earlier implementation refused =0,125= and accepted some malformed suffixes; this branch extends it and runs the existing tests alongside new regressions.
Independent review also caught zero-padded grouped tokens (=01,500=, =001,500=, =000,500=): the issue's rule reads these as 1500, 1500 and 500, while =0,500= remains decimal 0.5.
Unsupported exponent-like fragments with repeated signs or embedded whitespace now decline without changing existing range endpoints.
The ledger =.coder/ledger/1143-decimal-comma.md= records the source rules and recovery.
