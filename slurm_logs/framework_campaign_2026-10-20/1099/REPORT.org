* Result

A country-declared DataFrame table requested for a nonempty strict subset of known waves now returns a declared, finalized empty frame when none of those waves declares the table and no genuine country-level builder exists.
Both existing cache-hit gates return before any new wave-declaration inspection.
On a cache miss this happens before cache reconstruction, so cold, fresh, coverage-short, stale and LSMS_NO_CACHE cases answer consistently without replacing another wave's parquet or coverage manifest.
The existing =_empty_declared_frame= and =_finalize_result= supply shape, index and dtypes; neither received broader dtype behavior.
The implementation is limited to country.py's aggregation route plus a clarifying helper docstring.

Issue: https://github.com/ligon/LSMS_Library/issues/1099 .
Prior art and authorized boundary: .coder/ledger/1099-empty-subset.md, sections 2-5.
