* Reproduction

The scripts retain the exact allocation paths and source pins used for this run.
For a new allocation, replace the =/local/job40255479/= prefix and provision the two pinned checkouts and the frozen bundle before running them.
Use fresh, distinct writable roots and physical copies of the frozen bundle; do not run against a shared L2 or reuse the private result roots.
=run_audit.py= selects the runtime by its =baseline= or =combined= argument, asserts import identity and source pin, and runs the same combined scanner against either runtime.

Prepare the private copies before starting either controller.
The destination roots must not exist already.

#+begin_src python
from pathlib import Path
import shutil

bundle = Path('/global/scratch/fsa/fc_jevons/ligon/cache/.rewarm-bundle-94624fd6f/data')
root = Path('/local/job40255479/canonical-audit-compare')
root.mkdir(exist_ok=True)
for label in ['baseline', 'combined']:
    dest = root / f'data-{label}'
    assert not dest.exists()
    shutil.copytree(bundle, dest, symlinks=True, copy_function=shutil.copy2)
    assert sorted(str(p.relative_to(dest)) for p in dest.rglob('*') if p.is_symlink()) == ['dvc-cache']
    parquets = list(dest.rglob('*.parquet'))
    assert len(parquets) == 1519
    for p in parquets:
        assert p.stat().st_nlink == 1
        assert p.stat().st_ino != (bundle / p.relative_to(dest)).stat().st_ino
#+end_src
