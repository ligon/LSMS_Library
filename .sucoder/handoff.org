* Traps worth knowing (all cost time this session)

- =.pth= points at =/global/scratch/.../mirrors/LSMS_Library=, a THIRD
  checkout.  Always run wave scripts with both
  =PYTHONPATH=<clone>= and =LSMS_COUNTRIES_ROOT=<clone>/lsms_library/countries=,
  and assert =/local/job*/ in lsms_library.__file__=.
- =2005-06/_/categorical_mapping.org= has *mixed CRLF/LF* line endings.  A
  naive read/write normalises the whole file and buries the real edit in a
  372-line diff.  Preserve per-line terminators.
- Org tables *right-align numeric columns*.  Regenerating a wave table with a
  left-justifying writer rewrites every row.  Edit the changed LINES in place.
- =groupby().agg('sum')= returns *0.0 for an all-NA group*.  Use
  =min_count=1=, or phantom rows sail past a later =dropna(how='all')=
  (+32,040 of them here).
- Do not compute an "expected" row count from an assumed baseline.  Rebuild
  the true prior state and measure; that is what finally resolved a +637 that
  three rounds of reasoning had not.
- The shared mirror's =.venv= symlink points at whichever job last ran
  =bin/savio_venv.sh mount=.  Two agents on different nodes will ping-pong it.
  A clone's own =.venv= should point straight at its mount.
